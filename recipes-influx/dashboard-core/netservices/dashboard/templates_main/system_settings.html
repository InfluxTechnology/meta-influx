How ReXgen certificates work
Each device automatically generates its own unique SSL certificate on first use — no manual setup required. All ReXgen devices are signed by the same ReXgen Root CA, a company-wide certificate authority that is identical across every device we ship.

Installing the Root CA on your computer or phone is a one-time action. Once installed, your browser will trust all ReXgen devices automatically — no warnings, on any device, forever.
First time? Your browser will show a security warning when you first enable HTTPS. This is expected — the certificate is genuine but your browser has not yet been told to trust it. You can safely click "Advanced → Proceed" to continue, or install the Root CA below to remove the warning permanently.
