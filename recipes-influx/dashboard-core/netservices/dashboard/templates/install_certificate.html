Why is this needed?
This device uses HTTPS to encrypt your connection — so your password and data stay private on the network. Because the certificate is issued by this device itself (not by a global authority like Google or Let's Encrypt), your browser shows a security warning. That warning is safe to bypass here, but if you want no warnings at all, install the certificate below once and your browser will trust it permanently.

Click Download Certificate above — save the file rexgen-ca.crt.
2
Double-click the downloaded file. A dialog will open.
3
Click Install Certificate… → select Local Machine → Next.
4
Select Place all certificates in the following store → click Browse → choose Trusted Root Certification Authorities → OK → Next → Finish.
5
A security prompt may appear — click Yes to confirm.
6
Restart your browser. The warning will be gone.

1
Click Download Certificate above — save the file rexgen-ca.crt.
2
Open a terminal and run:
sudo cp ~/Downloads/rexgen-ca.crt /usr/local/share/ca-certificates/
sudo update-ca-certificates
On Fedora/RHEL use: sudo cp rexgen-ca.crt /etc/pki/ca-trust/source/anchors/ && sudo update-ca-trust
3
For Chrome / Chromium: go to Settings → Privacy → Manage certificates → Authorities → Import the file → check Trust for websites → OK.
4
For Firefox: go to Settings → Privacy & Security → View Certificates → Authorities → Import → check Trust to identify websites → OK.
5
Restart your browser. The warning will be gone.

3

Don't want to install it? That's fine — you can still use this dashboard by clicking "Advanced" → "Proceed anyway" on the browser warning page. Your connection is still encrypted; the warning only means the browser cannot automatically verify who issued the certificate.
